# 🚀 YBA OS — Ecosystem Platform

**YBA OS** — это веб-платформа для объединения молодых предпринимателей (Youth Business Association), предоставляющая финансовые инструменты, аналитику стартапов, систему вакансий и тендеров.

## 📌 Основной функционал

Платформа разделена на два роли-режима: **Участник (Member Mode)** и **Администратор (Admin Mode)**.

### 👤 Режим Участника (Member):
* **Бизнес-калькуляторы:** Расчет юнит-экономики (LTV/CAC), запаса хода средств (Runway) и Post-money оценки компании.
* **ИИ-Консультант:** Автоматический анализ метрик проекта с выдачей рекомендаций.
* **Финансовые инструменты:** Конвертер валют и мониторинг актуальных курсов (USD, EUR, CNY, RUB к KZT).
* **Модуль возможностей:** Просмотр доступных тендеров, вакансий и подача заявки на привлечение инвестиций.
* **Интерактив:** Чат с администратором и ежедневный генератор бизнес-цитат.

### 🛡️ Режим Администратора (Admin Dashboard):
* **Аналитический хаб:** Сводная таблица доходности, капитализации портфеля и прогнозируемой прибыли YBA.
* **Управление Deal Flow:** Модерация incoming-заявок от стартапов (одобрение / отклонение).
* **Менеджмент вакансий и тендеров:** Публикация новых задач, вакансий и просмотр откликов исполнителей.
* **Обратная связь:** Прямой чат для коммуникации с участниками экосистемы.

* **Хранение данных:** `LocalStorage` (для эмуляции базы данных в браузере)
* **Деплой:** GitHub Pages
